本分支为 SISSO 增加了在多维度 (desc_dim>1) 时固定若干维度描述符的能力。
======================================================================================================================
参数新增：SISSO.in 增加两项列表参数 <br>
fix_desc_dims=(1,3)：要固定的描述符维度列表（1-based）。<br>
fix_desc_exprs=(f1),(f2*f3)：对应维度要固定的表达式，需与 Uspace.expressions 中的表达式完全匹配，长度需与 fix_desc_dims 一致。<br>

全局存储：在 var_global 中增加 n_fix_desc, fix_desc_dim(:), fix_desc_expr(:), fix_desc_idx(:)，用于存储多条固定规则。<br>
解析与校验：SISSO.f90 解析上述参数，要求 desc_dim>1 时才能启用；会检查长度一致、维度范围合法、维度不重复。解析失败会直接报错退出。<br>
DI 集成：DI.f90 在读取 Uspace.expressions 后为每个固定表达式定位特征索引，强制加入活跃集；在组合枚举时仅保留包含所有已要求固定特征的组合；接受模型前会重排特征 ID 和系数，将固定特征放到指定维度。回归和分类两条路径均支
持。

使用方法
======================================================================================================================
在 SISSO.in 设置示例：<br>
desc_dim=3 <br>
fix_desc_dims=(1,3) <br>
fix_desc_exprs=(f1),(f2*f3) <br>
fix_desc_dims 与 fix_desc_exprs 长度一致，维度从 1 开始计数。 <br>
仅当 desc_dim>1 时生效。 <br>
确保 fix_desc_exprs 中的表达式存在于 Uspace.expressions 文件。 <br>
运行 SISSO，程序会在指定维度固定这些描述符，其余维度正常搜索。输出的模型与数据顺序保持固定维度规则。 

文件改动位置
======================================================================================================================
参数与默认值：SISSO/src/SISSO.f90 <br>
全局变量：SISSO/src/var_global.f90<br>
DI 逻辑（表达式匹配、活跃集补全、组合过滤、结果重排）：SISSO/src/DI.f90<br>
输入模板示例：SISSO/input_templates/SISSO.in<br>
如果表达式未找到或配置非法（长度不一致、维度越界、重复维度），程序会报错退出。
